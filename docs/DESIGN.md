# DESIGN — визуальный стиль

Статус: **временный минималистичный дизайн**. Финальный дизайн будет позже и подключается заменой токенов, поэтому в компонентах запрещены «зашитые» цвета, шрифты и размеры — только токены темы.

Референсы: `docs/design/logo.png` (логотип), `docs/design/ref-posts-*.png` (стиль постов), `docs/design/ref-predictions-table.png` (схема таблицы прогнозов, чужой сайт — только как структура).

## Библиотека дизайна (правило владельца)

Ключевые элементы дизайна собираются в `docs/design/` и **переиспользуются**, чтобы вид сайта был единым. Порядок работы, шаблон записи и каталог — `docs/design/README.md` и `docs/design/COMPONENTS.md`. Кратко: перед созданием UI проверь каталог; новый ключевой элемент → компонент + витрина `/styleguide` + снимок (`pnpm design:snap`) + запись в каталог; вне токенов ничего не рисуем.

## Характер

Спортивный, плотный, дерзкий, но чистый: белая основа, чёрные и жёлтые акценты, крупные узкие заголовки заглавными буквами, жирная типографика, много воздуха. Белорусский орнамент из логотипа — как редкий декоративный элемент (разделитель, фон блока), не на каждом экране.

## Токены (Tailwind theme / CSS variables)

| Токен | Значение | Использование |
|---|---|---|
| `--color-bg` | `#FFFFFF` | основной фон |
| `--color-ink` | `#000000` | основной текст, рамки, тёмные блоки |
| `--color-accent` | `#FEDE06` | жёлтый из логотипа: кнопки, акценты, выделение |
| `--color-muted` | `#6B6B6B` | вторичный текст |
| `--color-line` | `#E6E6E6` | разделители, границы карточек |
| `--color-surface` | `#F6F6F6` | фон карточек и зебры таблиц |
| `--color-success` | `#1FA84F` | точный счёт, зона лидеров (как в постах) |
| `--color-danger` | `#D6232A` | ошибка, неверный прогноз, ошибки форм |

Правила контраста: **жёлтый текст на белом запрещён** (не читается). Жёлтый — только как фон под чёрным текстом или как акцент на чёрном фоне. Минимальный контраст текста — WCAG AA.

## Типографика

- Заголовки: плотный узкий гротеск, заглавные (ориентир — Oswald/Anton; обязательна кириллица). Основной текст: Inter или системный гротеск.
- Подключение через `next/font`, subsets `cyrillic` и `latin`, шрифты и размеры — токены.
- Шкала: 14 / 16 (основной) / 20 / 28 / 40 / 56; на мобильных заголовки до 28–32.

## Компоненты (базовый набор в `src/components/ui`)

- **Кнопка**: основная — жёлтый фон, чёрный текст, чёрная рамка; вторичная — чёрный фон, белый текст; текстовая — подчёркивание. Высота ≥ 44 px.
- **Поля ввода**: белый фон, чёрная рамка 1–2 px, видимый фокус (жёлтая обводка + чёрная рамка), подписи всегда видны, ошибки под полем красным.
- **Карточки**: белый/светло-серый фон, тонкая рамка; акцентные — чёрный фон с жёлтым заголовком (как посты).
- **Таблицы** (рейтинг, прогнозы): строки с зеброй `--color-surface`; лидер/призёры подсвечиваются; на мобильных — компактные колонки, горизонтальный скролл только в крайнем случае; легенда сокращений под таблицей.
- **Шапка**: логотип слева; навигация (Главная, Прогнозы, Рейтинг), справа — вход/аватар. На мобильных — бургер или нижняя панель.
- **Бейджи результата**: «Точный счёт» (зелёный), «Исход» (жёлтый с чёрным текстом), «Мимо» (серый/красный).
- Состояния: загрузка (скелетоны), пусто (дружелюбный текст), ошибка (понятное сообщение + что делать).

## Адаптив

- Mobile-first, базовая ширина **360 px**, брейкпоинты Tailwind (`sm 640 / md 768 / lg 1024 / xl 1280`).
- Основной сценарий — телефон: поля счёта крупные (удобно вводить цифры, `inputmode="numeric"`), таблица прогнозов читается без горизонтального скролла.
- Десктоп: контейнер до 1200 px, больше воздуха, двухколоночные блоки (главная: плеер + список видео).

## Бренд-ассеты

- Из `docs/design/logo.png` сделать: логотип в шапке, favicon, OG-картинку (1200×630). Если у владельца есть SVG логотипа — использовать его.
- Логотипы клубов — загружает админ (квадрат или прозрачный PNG, ~256 px).

## Доступность

Контраст AA, видимый фокус, подписи у всех полей, `alt` у картинок, управление с клавиатуры, цель касания ≥ 44 px, информация не только цветом (бейджи с текстом).
