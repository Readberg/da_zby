# ROADMAP — эпики и релизы

Порядок построен так, чтобы каждый релиз давал работающий кусок, а админка появлялась раньше прогнозов (без неё нечего прогнозировать).

## План релизов

| Версия | Содержание | Эпики |
|---|---|---|
| `0.1.0` | Каркас, тема, главная с видео | E1, E2 |
| `0.2.0` | Вход, профили, онбординг | E3 |
| `0.3.0` | Админка: турниры, клубы, сезоны, туры, матчи, результаты, роли | E4 |
| `0.4.0` | Прогнозы | E5 |
| `0.5.0` | Рейтинг и статистика в профиле | E6 |
| `0.5.x` | Доработки по итогам первого реального тура (тестирование с друзьями/чатом) | — |
| `0.6.0` | Telegram-вход | E7 |
| `1.0.0` | Публичный запуск: прод, домен, финальный дизайн | E8 |

Даты не фиксируем. Честная оценка: ручная приёмка каждой задачи — узкое место; автопилот пишет код быстрее, чем вы успеваете проверять, поэтому один запуск ограничен целью `0.1.0`.

Каталог задач первого запуска с тест-кейсами — `docs/tasks/E1-E2.md`.

## Идеи в «Бэклоге» (тип «Анализ», пока не делаем)

- Прятать чужие прогнозы до дедлайна тура (если появятся жалобы на списывание).
- Пенальти и серия пенальти в Кубке.
- Автозагрузка расписания и результатов из API.
- Карточка «мой прогноз на тур» для сторис/репоста (бесплатный трафик из соцсетей).
- Ачивки («5 туров без промаха», «Антипрогнозист»), сравнение с прогнозами редакции.
- Опросы «игрок тура», рейтинг команд по версии аудитории.
- Отдельные роли админов (редактор матчей, модератор).
- Уведомления о приближении дедлайна (Telegram-бот/email).
- Монетизация (Boosty/донаты, мерч).
- Выбор инструмента аналитики (метка `analytics`).
- Rate limiting и ключи API для внешних клиентов (метка `api`).
- Другие типы турниров (`tournaments.kind`).
