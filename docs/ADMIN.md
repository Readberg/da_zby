# Админка-консоль и модераторы (D-139)

Как Django admin, без красоты: `/admin/data` (реестр сущностей), `/admin/data/<сущность>` (список с поиском, фильтрами, сортировкой, страницами, массовыми действиями), `/admin/data/<сущность>/<id>` (карточка, форма правки, действия), `/admin/data/audit` (журнал), `/admin/suspicious` (отчёт). Старые разделы турнира (`/admin/tournaments`, `clubs`, `seasons`, `users`) остались как были и доступны только админу.

## Как устроено
- **Реестр** `src/server/admin/registry.ts`: сущность → таблица, поля (тип, в списке, поиск, фильтр, сортировка, кто может править), действия. Новая сущность = один блок реестра; тест сверяет правила правки реестра с `admin_edit_rules` в миграции.
- **Права** `src/server/admin/permissions.ts` (user < moderator < admin). Проверяется: `withApi` (уровень `staff` → `is_staff()`), сервис (роль из `profiles` по `getUser()`), и ещё раз в БД (`adm_require`, правила по полям).
- **Правка** `adm_edit`: поле должно быть в `admin_edit_rules` и роль не ниже требуемой; нужна причина ≥ 5 символов; в `admin_audit` пишутся только изменённые поля «было → стало».
- **Действия**: заморозить/разморозить торги, убрать логотип (модератор); изменить бюджет (проводка `admin` в журнале денег, ниже нуля нельзя), превратить клуб в бота, вернуть из деактивации (ждёт `dormant` из DAZBY-151), сменить роль (последнего админа снять нельзя), удалить профиль (подтверждение вводом ника; клуб становится ботом по логике DAZBY-151), доиграть туры (`runRounds`, безопасно повторять: матч пишется один раз).
- **Отчёт «подозрительное»** `adm_suspicious()`: повтор пары в разных сезонах, продажи по потолку цены, лоты одному покупателю, два свежих аккаунта только друг с другом, одинаковый контакт, ставки только на лоты одного продавца. Только мягкие сигналы по данным игры; «проверено» хранится в `admin_reviews`. Ничего не блокируется.

## Права модератора (предложение, D-139)
Может: имена клубов и игроков, логотипы и фото, заморозка торгов, просмотр данных, журнала и отчёта, «проверено». Не может: деньги, роли, удаление, бот, туры, цвета и характеристики.
Назначить модератора: карточка профиля → «Сменить роль» (только админ).
