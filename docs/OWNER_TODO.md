### B2. Почта для писем входа (DAZBY-54)
Встроенная отправка Supabase имеет жёсткий лимит писем в час (точное значение — Supabase → Authentication → Rate Limits) и общий адрес отправителя. Для друзей и тестов хватает, для публичного запуска — нет.
- **Не подключать SMTP сейчас, вернуться перед публичным запуском (рекомендую).** Хорошая доставляемость требует собственного домена (SPF/DKIM), а домен вы покупаете в конце. Цена: ноль.
- Подключить сейчас Resend / Brevo (бесплатные тарифы есть; актуальные лимиты проверьте на их сайтах). Без своего домена письма чаще попадают в спам.

### B4. Вход через Telegram (DAZBY-8, E7) — ключевое решение
Telegram у Supabase «из коробки» нет, поэтому это отдельная доработка (≈1–2 дня), а не переключатель.
- **Как будет работать:** кнопка Telegram Login Widget → сервер проверяет подпись Telegram по токену бота → находит или создаёт пользователя → выдаёт сессию.
- **Что нужно от вас:** создать бота в @BotFather (`/newbot`), привязать домен сайта (`/setdomain`), токен бота положить только в Railway Variables (в чат не присылать). Также серверу понадобится `SUPABASE_SECRET_KEY` в Railway (в A4 мы его убирали — вернём ради этой функции).

- **Рекомендация:** сначала включить Google (A2) и выпустить на нём; Telegram делать следующим этапом после A2, когда вы создадите бота.
