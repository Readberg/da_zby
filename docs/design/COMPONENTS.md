# Каталог компонентов

Заполняется в ходе разработки (задача T-E1-11 и далее). Каждый ключевой элемент — отдельной записью. Не удаляй записи: помечай «устарел → заменён на …».
Снимки обновляются командой `pnpm design:snap` (поднимает dev-сервер, снимает секции `/styleguide` с атрибутом `data-snap` и экраны из `tests/design/snap.spec.ts`).

```

- Путь: src/components/ui/button.tsx
- Варианты / состояния: primary, secondary, text · hover, focus, disabled, loading
- Когда использовать: …
- Когда не использовать: …
- Доступность: …
- Где используется: страницы/компоненты (обновлять при новом использовании)
- Снимок: components/button.png
```

## Компоненты

### Кнопка (Button, buttonClasses)
- Путь: `src/components/ui/button.tsx`
- Варианты / состояния: `primary` (жёлтый фон, чёрная рамка), `secondary` (чёрный фон), `text` (подчёркнутая) · hover (инверсия цветов), focus (глобальная жёлтая обводка), disabled (50 % прозрачности).
- Когда использовать: любое действие. Для ссылок с видом кнопки — `<Link className={buttonClasses("primary")}>`.
- Когда не использовать: навигация в шапке (там `NavLink`); не ставить две `primary` рядом.
- Доступность: высота ≥ 44 px; по умолчанию `type="button"`, чтобы случайно не отправить форму.
- Где используется: 404, страница ошибки, `/styleguide`.
- Снимок: `components/button.png`

### Поле ввода (Label, Input, Textarea, Select, FieldError, TextField, TextareaField, SelectField)
- Путь: `src/components/ui/field.tsx`
- Варианты / состояния: однострочное поле, многострочное (`Textarea`, ≥ 112 px), список (`Select`); у каждого — обычное, с подсказкой (`hint`), ошибка (`error` → красная рамка и текст под полем), disabled.
- Когда использовать: формы. По умолчанию — `TextField` / `TextareaField` / `SelectField` (подпись + поле + подсказка/ошибка уже связаны); голые `Input`/`Textarea`/`Select`/`Label`/`FieldError` — для нестандартной раскладки.
- Когда не использовать: ввод счёта матча — будет отдельный компонент с `inputmode="numeric"` (E5).
- Доступность: подпись всегда видна; `aria-invalid`, `aria-describedby` на подсказку и ошибку; ошибка с `role="alert"`; высота ≥ 44 px.
- Где используется: вход (`/login`), онбординг, профиль (`/profile`), `/styleguide`.
- Снимок: `components/field.png`

### Админ-формы (турниры, клубы)
- `src/features/admin/components/{tournament-form,club-form,role-button}.tsx` — карточка `Card` с формой: поля `TextField`, флажок, кнопка с индикатором, статус «Сохранено» / «Проверьте поля», ошибки полей приходят и от сервера (`errors[].field`).
- Правила проверки общие для формы и API: `src/lib/admin-schema.ts`.

### Дизайн v2 (D-055)
- Кнопки: «таблетка», `primary` — жёлтая, `secondary` — чёрная, `text` — ссылка; без жирных рамок, Inter semibold. Кнопка Telegram — цвет `telegram`.
- Поля: рамка `line` 1 px, радиус 14, фокус — тёмная рамка и жёлтое кольцо. Карточки: радиус 24, фон `surface`, без рамки.
- Шапка: белая, `backdrop-blur`, прилипает; активный пункт — серая «таблетка». Подвал: светлый.
- Полоса прогресса навигации (`NavigationProgress`): жёлтая линия сверху, пока грузится следующая страница.

### Индикатор загрузки (Spinner) и кнопка в процессе
- Путь: `src/components/ui/spinner.tsx`; `<Button loading>` показывает кольцо, блокирует повторные клики и ставит `aria-busy`.
- Для страниц: `loading.tsx` с `PageLoading` (`src/components/layout/page-loading.tsx`) — скелет виден сразу при переходе.
- Движение: плавные смены цвета/фона 0,2 с, лёгкое нажатие (`scale .98`), появление страницы (`template.tsx`, `animate-page-in`), курсор-«рука» на всём кликабельном; при `prefers-reduced-motion` анимации отключаются.

### Профиль (ProfileView)
- Путь: `src/features/profile/components/profile-view.tsx` — шапка (фото, ник, имя, место), «О себе», контакты, даты, блок статистики; слот `actions` для кнопки «Редактировать» у владельца.

### Аватар (Avatar)
- Путь: `src/components/ui/avatar.tsx`
- Варианты: размеры `sm` 40 / `md` 64 / `lg` 128 px; с фото или заглушка — первая буква имени на жёлтом круге.
- Когда использовать: профиль, рейтинг, шапка. Фото декоративное (`alt=""`) — имя всегда рядом текстом.
- Когда не использовать: логотипы клубов (квадратные, отдельный компонент в E4).
- Где используется: публичный профиль `/u/[nickname]`, `/styleguide`.
- Снимок: `components/avatar.png`

### Карточка (Card)
- Путь: `src/components/ui/card.tsx`
- Варианты: `default` (светло-серый фон, тонкая рамка), `accent` (чёрный фон, жёлтый заголовок — как посты канала). Тег: `section` (по умолчанию) / `article` / `div`.
- Когда использовать: самостоятельный блок контента с заголовком.
- Когда не использовать: строки списков и таблиц; не вкладывать карточку в карточку.
- Доступность: `title` рендерится как `h3` — следить за иерархией заголовков страницы.
- Где используется: `/styleguide`.
- Снимок: `components/card.png`

### Бейдж результата (ResultBadge)
- Путь: `src/components/ui/badge.tsx`
- Варианты: `exact` «Точный счёт» (зелёный, чёрный текст), `outcome` «Исход» (жёлтый), `miss` «Мимо» (серый, красный текст).
- Когда использовать: результат прогноза в таблицах тура и профиле.
- Когда не использовать: статусы матчей и прочие метки — для них заведём отдельный бейдж.
- Доступность: смысл передаётся текстом, не только цветом; контраст ≥ AA (поэтому на зелёном чёрный текст).
- Где используется: `/styleguide` (в E5/E6 — таблицы прогнозов и рейтинга).
- Снимок: `components/badge.png`

### Таблица (Table, THead, TBody, TR, TH, TD)
- Путь: `src/components/ui/table.tsx`
- Варианты / состояния: зебра строк (`TBody`), подсветка строки (`TR highlight` — жёлтая, для лидера/«это я»), подпись-легенда (`caption`).
- Когда использовать: рейтинги, таблица прогнозов тура.
- Когда не использовать: раскладка страницы; списки из 1–2 полей.
- Доступность: `TH` со `scope="col"`, легенда сокращений в `caption`; горизонтальный скролл только как крайняя мера.
- Где используется: `/styleguide`.
- Снимок: `components/table.png`

### Контейнер (Container)
- Путь: `src/components/ui/container.tsx`
- Варианты: один — по центру, поля 16 px (24 px от `sm`), максимум 1200 px (`max-w-site`).
- Когда использовать: корневая колонка каждой страницы, шапка, подвал.
- Когда не использовать: внутри карточек и других блоков.
- Где используется: шапка, подвал, главная, 404, ошибка, `/styleguide`.
- Снимок: `components/container.png`

### Скелетон (Skeleton)
- Путь: `src/components/ui/skeleton.tsx`
- Варианты: размер задаётся классами (`h-6 w-40`, `aspect-video w-full`).
- Когда использовать: состояние загрузки блоков с известной формой (видео, строки таблицы).
- Когда не использовать: загрузка всей страницы без известной формы.
- Доступность: `role="status"` и подпись «Загрузка…».
- Где используется: `/styleguide`.
- Снимок: `components/skeleton.png`

### Шапка и подвал (SiteHeader, SiteFooter, NavLink)
- Путь: `src/components/layout/`
- Состояния: активный пункт меню — жёлтый фон и `aria-current="page"`; соцсеть без URL в `src/config/site.ts` не показывается.
- Когда использовать: только в корневом layout.
- Доступность: `nav` с подписями «Основная навигация» / «Мы в соцсетях»; внешние ссылки с пометкой «(откроется в новой вкладке)» для скринридеров.
- Снимок: экраны ниже.

### Витрина видео (VideoShowcase, LatestVideos, VideosUnavailable)
- Путь: `src/features/videos/components/`
- Состояния: загрузка (`LatestVideosSkeleton`), превью крупного видео с кнопкой ▶ → встроенный плеер `youtube-nocookie.com` (создаётся только по клику), сетка предыдущих (клик переключает и запускает плеер), запасной блок «Видео сейчас не загрузились» (акцентная `Card` + ссылка на канал).
- Раскладка: телефон — одна колонка; от 480 px сетка в 2 колонки; от 1024 px — плеер 2/3 и список справа.
- Когда использовать: главная. Для других списков видео — переиспользовать `VideoShowcase`.
- Доступность: кнопки с подписью «Смотреть видео: <название>», у iframe — `title`; превью декоративные (`alt=""`), название — текстом.
- Где используется: `/`.
- Снимок: экраны `screens/home-*.png`.
