## Компоненты

### Кнопка (Button, buttonClasses)
- Путь: `src/components/ui/button.tsx`
- Варианты / состояния: `primary` (жёлтый фон, чёрная рамка), `secondary` (чёрный фон), `text` (подчёркнутая) · hover (инверсия цветов), focus (глобальная жёлтая обводка), disabled (50 % прозрачности).
- Когда использовать: любое действие. Для ссылок с видом кнопки — `<Link className={buttonClasses("primary")}>`.
- Когда не использовать: навигация в шапке (там `NavLink`); не ставить две `primary` рядом.
- Доступность: высота ≥ 44 px; по умолчанию `type="button"`, чтобы случайно не отправить форму.
- Где используется: 404, страница ошибки, `/styleguide`.
- Снимок: `components/button.png`

### Поле ввода (Label, Input, Textarea, Select, FieldError, TextField, TextareaField, SelectField)
- Путь: `src/components/ui/field.tsx`
- Варианты / состояния: однострочное поле, многострочное (`Textarea`, ≥ 112 px), список (`Select`); у каждого — обычное, с подсказкой (`hint`), ошибка (`error` → красная рамка и текст под полем), disabled.
- Когда использовать: формы. По умолчанию — `TextField` / `TextareaField` / `SelectField` (подпись + поле + подсказка/ошибка уже связаны); голые `Input`/`Textarea`/`Select`/`Label`/`FieldError` — для нестандартной раскладки.
- Когда не использовать: ввод счёта матча — будет отдельный компонент с `inputmode="numeric"` (E5).
- Доступность: подпись всегда видна; `aria-invalid`, `aria-describedby` на подсказку и ошибку; ошибка с `role="alert"`; высота ≥ 44 px.
- Где используется: вход (`/login`), онбординг, профиль (`/profile`), `/styleguide`.
- Снимок: `components/field.png`

### Лоадеры (D-070)
- `BrandSpinner`/`Loader` (`src/components/ui/loader.tsx`): жёлтое кольцо с чёрной дугой; `Skeleton` отдаёт его вместо серого блока; `PageLoading` — лоадер вместо страницы при переходе; `SiteLoader` — крышка на первый заход (снимается по `load`, аварийно через 6 с).
- `Card interactive` — жёлтая рамка при наведении (без сдвига карточки: сдвиг под курсором давал мерцание).

### Одноэкранные страницы (D-068)
- `NarrowPage` (`src/components/ui/narrow-page.tsx`): заголовок по центру, строка пояснения и форма в мягкой карточке; вход и выбор ника. 404 и страница ошибки — по центру, «404» жёлтым.
- `Card` — рамка 1 px без тени; шапка админки — в карточке.

### Шапка и страницы (D-066)
- Шапка: «таблетки» навигации (активная — `bg-accent/30`), чёрная кнопка входа (`secondary`, инверсная в тёмной теме) с `UserIcon`; навигация на телефоне — вторым рядом.
- Выбор турнира/сезона/тура — в карточке `rounded-lg border border-line bg-surface p-4`; срок приёма — чип; матч — карточка; `Table` в рамке (`border-line`), места 1–3 — квадратные метки (1 — жёлтая, 2 — серая, 3 — с рамкой); «Ваше место» — плашка с жёлтой рамкой `border-accent/50 bg-accent/10`; очки жёлтым.

### Гостевая главная и подвал (D-065)
- `src/features/home/components/guest-landing.tsx`: `GuestLanding` (заголовок и CTA, `UpcomingMatches` — реальные матчи ближайшего тура, `Community` — ссылки на соцсети без цифр, три панели: жёлтая со шагами, «Пример рейтинга» в рамке телефона, чёрная с преимуществами, FAQ). `faq-list.tsx` — аккордеон (кнопки с `aria-expanded`, открыт один ответ).

- Яркие блоки панелей — фиксированные «брендовые» цвета (`bg-accent`, `bg-black text-white`), не зависят от темы.

- Тренд места в таблице рейтинга: ▲N (зелёный) / ▼N (красный) + подсказка; анимация `animate-trend-in`; рассчитывается `placeChanges`.

### Лендинг и принципы интерфейса (D-060)
- (устарело после D-071: `hero.tsx` стал `next-tour.tsx`, `how-it-works.tsx` удалён; живые шаги — в `guest-landing.tsx`) `src/features/home/components/{next-tour,leaders}.tsx`: `Hero` (обещание + одно главное действие + карточка «Ближайший тур»), `HowItWorks` (три шага, очки из турнира, склонение `pluralRu`), `Leaders` (пятёрка лидеров). ### Бейдж результата (ResultBadge)
- Путь: `src/components/ui/badge.tsx`
- Варианты: `exact` «Точный счёт» (зелёный, чёрный текст), `outcome` «Исход» (жёлтый), `miss` «Мимо» (серый, красный текст).
- Когда использовать: результат прогноза в таблицах тура и профиле.

- Доступность: смысл передаётся текстом, не только цветом; контраст ≥ AA (поэтому на зелёном чёрный текст).
- Где используется: `/styleguide` (в E5/E6 — таблицы прогнозов и рейтинга).

### Таблица (Table, THead, TBody, TR, TH, TD)
