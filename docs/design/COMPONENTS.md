## Шаблон записи

```
### Имя (Button)
- Путь: src/components/ui/button.tsx
- Варианты / состояния: primary, secondary, text · hover, focus, disabled, loading
- Когда использовать: …
- Когда не использовать: …
- Доступность: …
- Где используется: страницы/компоненты (обновлять при новом использовании)
- Снимок: components/button.png
```
