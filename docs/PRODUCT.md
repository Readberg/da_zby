# PRODUCT — что строим

Статус: утверждено владельцем (24.10.2026). Всё, чего нет в этом документе, в объём не входит.

## 1. Суть

Сайт блога «Да забей»: главная с видео канала и **турнир прогнозистов** (базовый турнир; в будущем возможны другие, поэтому турнир — сущность с настройками и типом `kind`) — зрители прогнозируют счета матчей по турам, получают очки и попадают в рейтинг. Аудитория: до ~1000 уникальных в месяц, почти все с телефонов (из Telegram, Instagram, TikTok, YouTube).

## 2. Роли

| Роль | Что может |
|---|---|
| Гость | Смотреть главную, профили, рейтинги, прогнозы других участников (после дедлайна тура) |
| Пользователь | Всё как гость + вести профиль, делать прогнозы |
| Админ | Всё как пользователь + управление турнирами, клубами, сезонами, турами, матчами, результатами, пользователями и ролями |

Первый админ — владелец проекта: при первом входе с подтверждённой почтой `wayreadberg@gmail.com` он автоматически становится админом с ником `Readberg` (механизм `admin_bootstrap`, см. `DATA_MODEL.md`). Админ может выдавать и снимать роль админа другим (сейчас у админа все права; в будущем появятся отдельные роли, поэтому доступ проверять через единую функцию `is_admin()` / серверный хелпер, а не размазывать проверки). Последнего админа снять нельзя.

## 3. Разделы и маршруты

Рекомендуемая схема маршрутов (можно уточнить в `DECISIONS.md`):

- `/` — главная
- `/login` — вход и регистрация
- `/onboarding` — обязательный шаг «придумай ник» (для новых пользователей без ника)
- `/profile` — свой профиль и редактирование
- `/u/[nickname]` — публичный профиль
- `/predictions` — прогнозы (выбор турнир → сезон → тур)
- `/rating` — рейтинг по турниру и сезону (и по туру)
- `/standings` — турнирная таблица чемпионата по сезону (D-115)
- `/support` — заглушка «Скоро» за кнопкой «Поддержать» в шапке; настоящая страница поддержки — отдельной работой (D-122)
- `/chat` — общий чат для вошедших (D-098)
- `/admin/...` — админка: турниры, клубы, сезоны/туры/матчи, пользователи

## 4. Главная

**Решение 25.10.2026 (D-065):** для гостей — лендинг по референсу владельца (заголовок, «Войти через Telegram», ближайшие матчи, сообщество без цифр, три панели, видео, FAQ); для вошедших — прежняя главная.

**Решение 26.10.2026 (D-060):** главная — лендинг для новых участников, а не новостной сайт. Сверху обещание и **одно главное действие** (гостю «Войти и сделать прогноз», вошедшему «Сделать прогноз»), рядом карточка «Ближайший тур» (матчи и дедлайн), ниже «Как это работает» в три шага (очки берутся из настроек турнира), «Лидеры сезона» и только потом видео канала. Цель: первый прогноз за 20–30 секунд без инструкций. Старое описание ниже оставлено как справка по блоку видео.

- Встроенный плеер с **последним видео** канала + сетка из **5 предыдущих**.
- Источник: RSS канала `https://www.youtube.com/feeds/videos.xml?channel_id=<ID>` (ID канала `@da_zby` определить по странице канала и записать в конфиг). Ключ API не нужен.
- Shorts в основной блок не попадают (проверить признак в ленте).
- Кеш 1 час. Если YouTube недоступен — показать последние закешированные данные или ссылку на канал, но не ломать страницу.
- Плеер подгружается лениво (превью-картинка → iframe `youtube-nocookie.com` по клику) ради скорости на мобильных.
- Ссылки на соцсети (YouTube, Telegram, Instagram, TikTok) — в шапке/подвале.

## 5. Вход и регистрация

- Способ один: **Telegram** (D-054). Отдельных паролей, почты и Google нет.
- Регистрация = первый вход. После первого входа, если у профиля нет ника, пользователя перенаправляет на `/onboarding`, пока он не введёт ник. Без ника остальной функциональности нет.
- Имя при входе подтягивается из Telegram (можно изменить в профиле). Почты у аккаунта нет.

| 8 | Страна, город | страна — выпадающий список, город — ручной ввод (решение владельца 25.10.2026: подсказки не нужны) | всем |
| 9 | Таблица статистики | автоматически (ниже) | всем |

**Ник**: 3–20 символов, буквы (латиница/кириллица), цифры, `_`; уникален без учёта регистра. Можно менять в любой момент в «Редактировать профиль» (D-061).
Профиль виден гостям без входа. Страница `/profile` показывает свой профиль так, как его видят другие, с кнопкой «Редактировать»; форма и фото — на `/profile/edit`.

**Таблица статистики** — по строке на каждую пару «турнир + сезон», где у пользователя есть прогнозы:
Турнир · Сезон · Прогнозов · Побед · Поражений · Очков · % побед · Место в рейтинге.
«Место» — текущее, пока сезон идёт; после закрытия сезона фиксируется итоговое (с отметкой «итог»).

## 7. Прогнозы

Страница прогнозов: сверху выбор **Турнир → Сезон → Тур** (список заводит админ; по умолчанию открывается актуальный тур).

Таблица матчей тура (ориентир — `docs/design/ref-predictions-table.png`): дата и время (в часовом поясе пользователя) · хозяева (логотип + название) · **поле счёта** (два числа «хозяева : гости») · гости · итог матча (после завершения) · полученные очки.

Правила:
- Прогноз — **счёт** матча. Можно менять сколько угодно раз до дедлайна.
- **Дедлайн — на весь тур: за 10 минут до начала первого матча тура** (админ может вручную закрепить другой дедлайн). После дедлайна поля блокируются; в БД тоже запрещены.
- Очки (настраивает админ в настройках турнира): точный счёт — **3**, верный исход (победа/ничья/поражение) — **1**, ошибка — **0**.
- Считаются очки автоматически сразу после того, как админ внёс результат матча. Если админ исправил результат или настройки очков — пересчитываются.
- Учитывается **итоговый счёт с учётом доп. времени, без серии пенальти** (пенальти пока не заводим).
- Матч перенесён → статус «перенесён», очки по нему не считаются, пока админ не внесёт результат. Отменён → исключается.
- Не сделанный прогноз = нет записи; он **не считается** ни поражением, ни прогнозом.
- **Чужие прогнозы скрыты до дедлайна тура** (D-084): до него в рейтинге тура написано «Прогнозы участников откроются после дедлайна тура — дата», свои прогнозы видны на этой странице всегда, админ видит все. После дедлайна (или когда матч завершён) в рейтинге тура видны прогнозы всех. Данные для общего просмотра кешируются на 30 минут, а таблица тура до дедлайна — не дольше, чем до дедлайна. Свои прогнозы всегда актуальны.
- Ссылка на рейтинг этого турнира и сезона.

## 8. Рейтинг

- Сверху выбор Турнира и Сезона (если пришли со страницы прогнозов — уже выбраны).
- Таблица: **Место · Участники · Неверных прогнозов · Угадано исходов · Угадано счетов · Сумма очков**.
- По умолчанию — общая таблица сезона. Можно открыть **конкретный тур**: по каждому матчу тура видно прогноз участника и что получилось (точный счёт / исход / мимо).
- Сортировка: очки ↓, затем число точных счетов ↓, затем число угаданных исходов ↓. Если всё равно — **одинаковое место** (дата регистрации не учитывается).
- Клик по участнику → его публичный профиль.
- **Длинная таблица (D-084):** показаны топ-20 и строка самого участника; пропущенные участки отмечены «… ещё N участников». Кнопка «Показать соседей» (параметр `?around=1`) добавляет 5 строк выше и 5 ниже своей; «Скрыть соседей» возвращает короткий вид. Гость видит топ-20. Короткая таблица (до 20) показывается целиком. Над таблицей — «Ваше место».
- Полные названия колонок на десктопе; на мобильных допустимы сокращения (Н / И / С / Σ) с обязательной легендой под таблицей.

## 8б. Турнирная таблица чемпионата (D-115)

- Страница «Таблица» (в меню после «Рейтинга»; по-английски «League table») — **таблица реального чемпионата**, не рейтинг прогнозистов. Сверху выбор Турнира и Сезона.
- Колонки: **№ · Клуб · И · В · Н · П · М (забитые–пропущенные) · О · Форма** (последние 5 результатов, буквы В/Н/П и цвет). На телефоне видны №, клуб, И, М, О; В/Н/П — с планшета, форма — с `md`.
- Считается из наших матчей сезона: победа — 3 очка, ничья — 1; в таблице только завершённые матчи со счётом (перенесённые и отменённые не считаются). Все клубы состава сезона видны с первого дня.
- Порядок: очки ↓, разница мячей ↓, забитые ↓, затем название. У клубов, равных по всем трём, место одинаковое. Это упрощение: личные встречи не учитываются.
- Под таблицей честно: «Учтено матчей: N из M» — таблица точна, пока внесены все результаты сезона.
- Кеш общий, как у рейтинга: сбрасывается, когда админ вносит результат.

## 8а. Чат (D-098)

- Доступен только вошедшим (с ником); гость при заходе на `/chat` попадает на вход и возвращается обратно. Ссылка «Чат» в основном меню.
- **Окно чата на десктопе (от 1024 px, D-105).** В правом нижнем углу каждой страницы: по умолчанию свёрнуто в круглую кнопку, раскрывается и сворачивается (крестик или Esc), при прокрутке остаётся на месте. Выбор запоминается в браузере: оставили открытым — при следующем заходе открыто. На каждом устройстве своё. На телефоне окна нет, чат — страница `/chat`; на самой странице `/chat` окно не показывается.
- Одна общая комната. Сообщения доходят мгновенно (Supabase Realtime), статус связи показан над списком.
- Сообщение — 1–500 символов, не чаще одного в 2 секунды. Enter отправляет, Shift+Enter — новая строка.
- **Сообщения живут 24 часа**: старше суток не показываются и физически удаляются из базы; в резервные копии не попадают.
- Автор удаляет своё сообщение; админ удаляет любые и может закрыть участнику доступ к чату (участник видит уведомление вместо формы).

## 9. Админка

Доступна роли админ. Всё делается через интерфейс:
- **Турниры**: название, slug, очки за точный счёт и исход, активность. При смене очков — кнопка «пересчитать сезон».
- **Клубы**: общий справочник (название, краткое название, логотип). Все клубы заводит владелец вручную.
- **Сезоны**: создание, состав клубов сезона (можно копировать с прошлого), **закрыть сезон** (фиксирует итоговые места) и **откатить закрытие**.
- **Туры и матчи**: номер/название тура, матчи (хозяева, гости, дата и время начала), статус, внесение результата. Заполняется вручную или импортом: кнопка «Показать, что изменится» в туре берёт тур лиги с тем же номером из TheSportsDB, показывает новые матчи, переносы времени и результаты, и применяет только отмеченное (D-090). Время вводится в часовом поясе админа (из профиля) и хранится в UTC; клубы для матча выбираются из состава сезона. Закрытый сезон нельзя править, пока не откатить закрытие. Тур с матчами и матч с прогнозами не удаляются (матч ставят в «отменён»).
- **Пользователи**: список, поиск, выдача/снятие роли админа, правка профиля участника (ник, имя, контакт, о себе, страна, город, пояс; фото можно только убрать) — D-094.

## 10. Глоссарий (полные названия, чтобы не было путаницы)

| Термин | Определение |
|---|---|
| Прогноз | Предсказанный пользователем счёт одного матча |
| Точный счёт (С) | Прогноз совпал с итоговым счётом полностью |
| Угадан исход (И) | Счёт не совпал, но верно предсказан исход: победа хозяев, ничья или победа гостей |
| Неверный прогноз (Н) | Не угадан ни счёт, ни исход |
| Победа (в статистике профиля) | Прогноз с точным счётом или верным исходом |
| Поражение (в статистике профиля) | Неверный прогноз |
| % побед | Победы ÷ (победы + поражения) по оценённым прогнозам |
| Сумма очков | Сумма очков за все оценённые прогнозы |
| Тур | Набор матчей одного игрового этапа турнира (в Кубке — например, «1/16 финала») |
| Сезон | Розыгрыш турнира за период; у каждого сезона свой рейтинг |
| Дедлайн тура | За 10 минут до начала первого матча тура |

## 12. Нефункциональные требования

Mobile-first; быстрая загрузка (LCP < 2.5 с на среднем 4G); доступность (контраст, фокус, подписи полей); безопасность по `ARCHITECTURE.md`; SEO-база (метаданные, OG-картинка, sitemap).

### Telegram Mini App (D-128)
- Сайт открывается в Telegram как мини-приложение (кнопка меню бота, ссылка `t.me/<бот>/<имя>`): тот же сайт и весь функционал. Вход автоматический (подпись Telegram, без числа из трёх), язык берётся из Telegram, пока не выбран на сайте, на внутренних страницах работает кнопка «Назад» Telegram, ссылки на другие сайты открываются средствами Telegram, при сохранении прогноза короткая вибрация.
- Ссылки с `?startapp=rating|standings|predictions|chat|profile|support` открывают нужный раздел.
- Не поддерживается: Telegram Web (в браузере).
