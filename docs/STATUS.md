## Временные соответствия Jira (до настройки проекта владельцем)

Проект DAZBY — бизнес-шаблон: типы «Рабочий процесс / Задача / Подзадача», статусы «К выполнению / В работе / Готово».
- Эпик → тип «Рабочий процесс» (метка `epic`).
- Анализ / Баг → тип «Задача» с меткой `analysis` / `bug`, в названии префикс `[Анализ]`.
- «Тестирование» → статус «В работе» + метка `testing`.
- «Бэклог» → статус «К выполнению» + метка `backlog`.

## Блокеры (нужно от владельца) — подробно в DAZBY-1

1. `gh auth login` — без него нет PR; задачи вливаются в `dev` локальным squash-мержем с описанием PR в сообщении коммита.
2. Jira: типы Эпик/Баг/Анализ, статусы Бэклог/Тестирование.
3. Supabase: применить миграции через SQL Editor, `SUPABASE_SECRET_KEY` в `.env.local`, Redirect URL.
