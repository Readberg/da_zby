# Fonts for generated images (D-091)

`PTSans-Bold-subset.ttf` is PT Sans Bold (ParaType, SIL Open Font License, see `OFL-PTSans.txt`) cut
down to Latin, Cyrillic and a few symbols (≈ 30 KB) with `pyftsubset`. The Open Graph images use
it because the image renderer needs a static TTF and the site fonts are variable web fonts.
